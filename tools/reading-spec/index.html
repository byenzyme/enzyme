Language reference & execution boundaries

      
Profiles are values
profile decisions {
  seek "why one path won"
  notice ["assumptions", "tradeoffs"]
}
Use a name after about, or embed profile { … } directly. let decisions = profile { … } is equivalent. Built-in names work without a declaration.

      
Defaults flow downward
learning {
  sample by recency
  question budget 40
}
Global → vault → reading. The last scope wins. Sampling and recency settings feed generation. Changes become part of the refresh fingerprint.

      
Guidance stays guidance
when asked {
  "Use grep for exact phrases."
  retrieve passages through learned questions
  answer with sources
}
Quotes compile to agent instructions. They are not model-evaluated conditions, automatic hooks, or permission to write. Nothing runs against your vault here.

      
Honest compilation
The same Rust parser powers this playground and init/refresh. Custom profiles enter generation prompts; linked pages inherit explicit parent readings unless separately configured. Download a .enzyme file for your configs directory.
Question budget means the largest entity’s allocation, scaled by document count with a floor of 3. It is separate from the document embedding limit. No expiry policy is implemented.
